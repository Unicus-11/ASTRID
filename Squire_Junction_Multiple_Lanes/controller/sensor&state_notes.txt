ASTRID - SENSOR AND STATE EXTRACTOR
===================================

RUNNING
-------

From the controller folder:

    cd controller
    python state_extractor.py

The script runs SUMO and generates:

    GPS observations
    CCTV observations
    SUMO Ground Truth


1. GPS
------

GPS represents sparse connected/probe vehicles.

id            = vehicle ID
position      = current x,y position
speed         = vehicle speed
edge          = current road segment
lane          = current lane
vehicle_type  = vehicle class
timestamp     = simulation time

GPS only observes selected probe vehicles,
not every vehicle.


2. CCTV
-------

CCTV represents roadside cameras.

id            = vehicle ID
camera_id     = camera that detected the vehicle
position      = current x,y position
speed         = vehicle speed
edge          = current road segment
lane          = current lane
lane_position = position along the lane
vehicle_type  = vehicle class
timestamp     = simulation time

CCTV only observes vehicles inside its
camera coverage.


3. SUMO GROUND TRUTH
--------------------

Ground truth is the complete information
available from SUMO.

id            = vehicle ID
position      = current position
speed         = current speed
edge          = current road segment
lane          = current lane
lane_position = position along lane
route         = complete route of the vehicle
route_index   = current position in the route
movement      = higher-level movement
vehicle_type  = vehicle class
timestamp     = simulation time


ROUTE vs MOVEMENT
-----------------

Route = sequence of road edges.

Example:

    4i -> 2o

Movement = meaning of that route.

Example:

    north_to_east

Movement is derived from the route.


WHY GROUND TRUTH IS SEPARATE
----------------------------

Sensors provide incomplete information.

    GPS + CCTV
         |
         v
    Future AI Model
         |
         v
    Estimated Hidden State

SUMO provides the correct answer:

    SUMO Route/Movement
           |
           v
    Training Label / Ground Truth

We do NOT give route or movement to GPS/CCTV.
The future model must learn to estimate it
from sensor observations.

# IMPORTANT:
# Sensor data does NOT contain the vehicle's intended movement.
# GPS and CCTV only provide observable information such as
# position, speed, lane, and time.
#
# The neural network will later learn to estimate the hidden
# movement/state from these sensor observations.
#
# During training, SUMO provides the actual route/movement.
# This acts as the ground-truth label for the neural network.
#
# Therefore:
#
#     Sensor observations -> Neural Network -> Estimated movement
#                                      ↑
#                           trained using SUMO movement
#
# We must NOT put SUMO's route/movement into GPS or CCTV data,
# because that would give the model the answer directly.
